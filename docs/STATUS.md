## Publication rules for project claims

Report measured successes with their scope, and show unknown/unavailable states.
Do not turn five returned analytics rows into eight, a disposable repair into a
production fix, an Expo export into a signed IPA, or a source test into installed
behavior. Do not claim perfect content, guaranteed revenue, guaranteed views,
consciousness, universal autonomous repair or physical phone validation.

This documentation pass performed no production inference, uploads, builds,
installation or live-account changes. AutoClip findings are vendor documentation
research, separately scoped in [the comparison](AUTOCLIP_COMPARISON.md).
