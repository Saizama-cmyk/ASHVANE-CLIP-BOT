# Development tools

Reviewed 2026-10-11 following the owner's suggestions. These are tools for building
Ashvane and its creative workflows; they are not additional business workspaces.

## Diagram Design

[Official repository](https://github.com/cathrynlavery/diagram-design).
An agent skill for self-contained HTML/SVG diagrams. Installed locally at
`C:/Users/wilco/.codex/skills/diagram-design`; a new Codex session is needed to load
the installed skill. It is not bundled into the Ashvane desktop or phone app.

Useful for visualizing queue stages, account ownership, business boundaries and
failure/recovery paths while planning or explaining changes. This can make design
mistakes easier to spot; the diagrams themselves do not improve runtime speed or
replace tests. No diagram has been generated with it for this update.

## ArtCraft

[Official repository](https://github.com/storytold/artcraft) and
[pricing](https://getartcraft.com/pricing).
The project documents 2D composition, 3D scene staging, character posing and camera
placement for AI image/video production. Those controls may help plan consistent
Hollow shots, Social Studio visuals and Ashvane visual assets.

The public desktop source is MIT/Apache-2.0. Generation is not inherently free:
the service sells credit plans, and states that third-party subscriptions or your
own compute can be used. Compatibility with our local engines, unattended use and
an Ashvane automation interface have not been verified. No ArtCraft app, service,
subscription or runtime integration has been installed by this update. Evaluate a
small original scene against our existing production workflow before adopting it;
retain the project's local/free requirement.
